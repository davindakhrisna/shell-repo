# shell-repo

Personal collection of small shell tools, daemons, and dotfiles to help with day-to-day terminal and homelab tasks.

Quick start

```bash
git clone https://github.com/davindakhrisna/shell-repo.git
cd shell-repo
# (optionally) add bin/ to your PATH
export PATH="$PWD/bin:$PATH"
```

What's here

- auto-vc/ — lightweight git daemon for automatic commits and pushes (see auto-vc/README.md)
- photo-gallery/ — automated capture & upload daemon for homelab cameras (see photo-gallery/README.md)

Each subfolder contains its own README with install, config, and usage details — check them for examples and full instructions.
